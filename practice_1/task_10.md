# Задача 10. Пустые текстовые файлы в директории

## Задание

Написать программу, которая выводит названия всех пустых текстовых файлов в указанной директории. Директория передаётся параметром.

## Код программы

```bash
#!/usr/bin/env bash
[[ $# -ne 1 ]] && { echo "Использование: $0 <каталог>" >&2; exit 1; }
[[ -d "$1" ]] || { echo "Ошибка: каталог $1 не найден" >&2; exit 1; }
find "$1" -type f -size 0 -printf '%P\n'
```

## Проверка

```text
$ ./task10 dup
empty2.txt
a/empty.txt
```

Выводятся только пустые файлы.
