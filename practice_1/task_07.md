# Задача 7

## Задание

Написать программу для нахождения файлов-дубликатов (имеющих 1 или более копий содержимого) по заданному пути и подкаталогам.

## Код программы

```bash
#!/usr/bin/env bash
[[ $# -ne 1 ]] && { echo "Использование: $0 <путь>" >&2; exit 1; }
find "$1" -type f -exec md5sum {} + |
    sort |
    awk -F'  ' '$1==p {print pn; print $2} {p=$1; pn=$2}' |
    sort -u
```

## Проверка

```text
$ ./task7 dup
dup/a/f1.txt
dup/b/f2.txt
dup/f3.txt
```

Найдены файлы с одинаковым содержанием. Уникальные файлы в результат не попадают.
