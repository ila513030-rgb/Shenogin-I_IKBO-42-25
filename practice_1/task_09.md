# Задача 9. Замена 4 пробелов на табуляцию

## Задание

Написать программу, которая заменяет в файле последовательности из 4 пробелов на символ табуляции. Входной и выходной файлы задаются аргументами.

## Код программы

```bash
#!/usr/bin/env bash
in="$1"; out="$2"
[[ -n "$in" && -n "$out" ]] || { echo "Использование: $0 <входной_файл> <выходной_файл>" >&2; exit 1; }
[[ -f "$in" ]] || { echo "Ошибка: файл $in не найден" >&2; exit 1; }
perl -pe 's/ {4}/\t/g' "$in" > "$out"
echo "Готово: $out создан"
```

## Проверка

```text
$ ./task9 in.txt out.txt
Готово: out.txt создан

$ cat -A out.txt
aaaa^Ibbbb^I^Icccc$
```

`^I` — символ табуляции.
